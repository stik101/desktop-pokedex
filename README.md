

# Desktop Pokedex

A mini floating desktop Pokédex made with <3 using **Godot 4**.

Imagine owning your very own complete Pokédex...in your desktop.

_Inspired by those mini widgets we had in Windows 7, but for Poké-Geeks lol._

> ⚠️ This project is still a work in progress.
> Feel free to reuse this project for your own purpose, go crazy yo.

---

## ✨ Features

**DONE ✅**

-  Floating, draggable desktop window
-  Transparent & borderless window
-  Click-through transparent areas
-  Pokémon search by NAME or ID
-  Pokémon cries
-  Pokémon descriptions
-  Base stats
-  Moves
-  Animated opening/closing Pokédex
-  Types

**WIP ⚠️**
- Pokémon seach by Snippet [REQUIRES YOUR OWN GENAI API KEYS]
- Themes inspired by different generations
- Mini desktop pokemons
- Evolution chains
- Abilities
---

## 🛠️ Built With

- [Godot 4](https://godotengine.org/) - Primary Tool/Game Engine
- [PokéAPI](https://pokeapi.co/) - Primary REST API relied on
- GitHub-hosted Pokémon sprites and cries (from PokéAPI)
